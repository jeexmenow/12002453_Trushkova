# Лабораторная работа 2 (семестр 2). Spring MVC

Трушкова А.И., группа 12002453

## Цель

Получить практические навыки работы со Spring MVC: модель, представление Thymeleaf, контроллер, сервис и репозиторий.

## Что сделано

Проект лежит в `app`. Это список дел в памяти.

- `Task` — модель: номер, название, описание, статус.
- `TaskRepository` — хранение списка в памяти.
- `TaskService` — добавление, просмотр, смена статуса и удаление.
- `TaskController` — маршруты страницы.
- `templates/index.html` — страница списка и форма новой задачи.

Маршруты совпадают с примером из методички:

| Метод | Адрес | Действие |
|---|---|---|
| GET | `/` | Страница со списком |
| POST | `/addTask` | Новая задача |
| POST | `/updateTask/{id}` | Смена статуса |
| GET | `/deleteTask/{id}` | Удаление |

Контроллер из примера держит список у себя. Здесь список лежит в репозитории, а контроллер вызывает сервис: так устроены слои, которые методичка описывает отдельно.

## Дополнительное задание

В методичке шесть вариантов, варианта 18 нет. Номер 18 снова даёт пункт 6: `(18 - 1) mod 6 + 1 = 6` — улучшить внешний вид `index.html`.

Страница оформлена отдельно от голого списка из примера:

- лист на тёплом фоне, карточки задач;
- счётчик «в работе» и «готово»;
- пустое состояние;
- у выполненной задачи зачёркнутое название и кнопка «Вернуть».

## Запуск

Нужны JDK 21 и Maven. Из каталога `app`:

```bash
mvn spring-boot:run
```

Страница: <http://localhost:8080/>

## Проверка

```bash
mvn test
```

Тест добавляет задачу, отмечает её готовой и удаляет.
