# Лабораторная работа 6 (семестр 2). Клиент под Android

Трушкова А.И., группа 12002453

## Цель

Получить практические навыки работы со Spring Framework: мобильный клиент запрашивает список дел у уже готового сервера.

## Что сделано

Проект лежит в этой папке и открывается в Android Studio. Сервер — приложение из лабораторной работы 5 (`sem2/lab5/app`): `GET /api` с заголовком `Authorization: Basic`.

Клиент на Java:

- `LoginActivity` читает логин и пароль, кодирует их в Base64 и открывает список;
- `TaskManagerActivity` через Retrofit запрашивает `http://10.0.2.2:8080/api` и показывает описания в `RecyclerView`.

Адрес `10.0.2.2` — это компьютер с точки зрения эмулятора Android. Для него в `network_security_config.xml` разрешён обычный HTTP. В манифесте запрошено разрешение `INTERNET`.

Пароль учётных записей сервера: `password`. Подойдут `user`, `editor` и `moderator`.

## Дополнительное задание

В методичке дополнительных пунктов и номеров вариантов нет. Сделан клиент по примеру: вход и вывод списка задач.

## Запуск

Нужны Android Studio и запущенный сервер пятой работы. PostgreSQL — на `localhost:5432`, база `todo_db`, пользователь и пароль `postgres`.

Сервер, из `sem2/lab5/app`:

```bash
mvn spring-boot:run
```

Клиент: открыть папку `sem2/lab6` в Android Studio, дождаться синхронизации Gradle и запустить приложение на эмуляторе.
