# Лабораторная работа 3 (семестр 2). Spring Security

Трушкова А.И., группа 12002453

## Цель

Получить практические навыки работы со Spring Security: вход по форме, роли и ограничение действий в списке дел.

## Что сделано

За основу взят список дел из лабораторной работы 2. Проект лежит в `app`.

Добавлены `spring-boot-starter-security` и страница входа. Пользователи хранятся в памяти, пароль у всех один: `password`.

| Логин | Роль | Что можно |
|---|---|---|
| user | USER | Смотреть список и добавлять задачи |
| editor | EDITOR | Ещё менять статус: «Отметить готовой» и «Вернуть» |
| moderator | MODERATOR | Ещё и удалять задачи |

В методичке смена статуса и удаление закрыты ролью `MODERATOR` через `@PreAuthorize`. Здесь удаление по-прежнему только у модератора. Смена статуса открыта и модератору, и редактору.

В Spring Boot 3 вместо `@EnableGlobalMethodSecurity` из примера стоит `@EnableMethodSecurity`: это тот же доступ к `@PreAuthorize`.

Если роли не хватает, открывается страница «Недостаточно прав».

## Дополнительное задание

Нужно добавить одну или две роли под функционал прошлой работы. Варианта с номером 18 в методичке нет.

Добавлена роль `EDITOR`. Она пользуется сменой статуса из работы 2, включая кнопку «Вернуть», и не может удалять задачи.

## Запуск

Нужны JDK 21 и Maven. Из каталога `app`:

```bash
mvn spring-boot:run
```

Страница входа: <http://localhost:8080/login>

## Проверка

```bash
mvn test
```

Тест проверяет вход, запрет смены статуса и удаления для `user`, смену статуса без удаления для `editor` и удаление для `moderator`.
